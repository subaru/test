nihon-tidy の使い方

日本語のデータ（CSV・JSON・Excel・HTML・テキスト）の列の種類を推論し、正規化して、何を変えたかを記録・表示する JavaScript ライブラリです。

このページの例は、ブラウザの中で実際に動きます。「実行」を押すと結果が表示されます。データは外部に送られません。

nihon-tidy とは

バラバラな書き方のデータを、決まった形にそろえます。処理は次の流れです。

読み込み read→ 列の種類の推論 detect→ 正規化 normalize→ 表記ゆれの統一 cluster→ 表示・レポート・書き出し
列の種類入力 → 正規化後の例
日付令和6年4月1日 → 2024-04-01、S60.4.1 → 1985-04-01
電話番号０３（１２３４）５６７８ → 03-1234-5678
郵便番号〒150ー0002 → 150-0002
数値¥12,000 → 12000、1万2千円 → 12000、△500 → -500
真偽値○ → true、× → false
フリガナﾔﾏﾀﾞ ﾀﾛｳ → ヤマダ タロウ
メールInfo@ABC.CO.JP → Info@abc.co.jp
すべての列全角英数字→半角、半角カナ→全角、余分な空白を詰める
迷ったら変換しない：確信度が低い変換（既定では 0.9 未満）は適用せず「提案」として残します。変更はすべて記録され、あとから確認・適用・取り消しができます。

準備

このページを開く

ES Modules を使うため、HTML ファイルをダブルクリックで開いても動きません。リポジトリのフォルダで次のどちらかを実行し、表示された URL を開きます（Node.js 18 以上が必要）。

npm run docs
# または
node scripts/serve.js
# → http://127.0.0.1:8080/docs/usage.html

Windows では docs\start-docs.bat をダブルクリックしても起動できます。

自分のページで使う

<script type="module">
  import { tidy } from './nihon-tidy/src/index.js';   // リポジトリの src を置いた場所
  // npm に公開した後は：import { tidy } from 'nihon-tidy';
</script>

Node.js（18 以上）でも同じ API が使えます：import { tidy } from './src/index.js'

はじめての正規化

tidy(入力, オプション) を呼ぶだけです。結果の data が正規化後のデータ、changes が変更の記録です。

入力の種類

形式は自動で判定します（format オプションで指定も可）。

渡せるもの内容
文字列CSV・TSV・JSON・HTML・テキスト
File・Blob<input type="file"> で選んだファイルなど。Shift_JIS も自動判定
ArrayBuffer・Uint8Arrayバイト列（Excel の .xlsx も）
オブジェクトの配列[{ 氏名: '山田', 電話: '…' }] のような、API やスクレイピングの結果

ファイル選択から読み込む場合：

input.addEventListener('change', async () => {
  const result = await tidy(input.files[0]);
});

オプション

オプション内容
format'csv' | 'json' | 'xlsx' | 'html' | 'text'（既定は自動判定）
delimiterCSV の区切り文字（既定は自動判定）
headerfalse で見出しなし（列名は 列1…）
sheetExcel のシート名か番号（0 から）
headerRowExcel の見出し行（0 から。既定は自動）
headerRowsExcel の見出しの段数（1 以上の整数。既定は自動）
tableHTML のページ内の表の番号
columns列ごとの指定。{ コード: { type: 'text' }, 備考: { cluster: false } }
minConfidenceこれ未満の確信度の変換は提案にとどめる（既定 0.9）
clusterfalse で表記ゆれの統一をしない
threshold / hintedThreshold列の種類と判定する一致率（既定 0.7 / 列名にヒントがあるとき 0.5）
plugins['address'] や独自のプラグイン

結果の中身

プロパティ内容
data正規化後のデータ（オブジェクトの配列）
schema列ごとの推論結果：name・type・label・confidence（一致した割合）・candidates など
changes変更の記録：row・column・before・after・rule・note・confidence・applied（適用したか）
issues要確認：解釈できなかった値など。row・column・value・reason
clusters表記ゆれのまとまり：canonical（統一後）・variants・applied
meta読み込みの情報：source・encoding・sheet・headerRows など

提案の適用と手直し

確信度が低く適用しなかった変換（applied: false）は、あとから適用できます。行番号は data の添字（0 から）です。

メソッド内容
accept(row, column)その提案を適用する（適用したら true）
acceptAll()提案をすべて適用する（適用した数を返す）
dismiss(row, column)提案を「そのまま」にする
fix(row, column, value, note?)値を手で直す（変更ログに「手動」として残る）
setCanonical(index, value)表記ゆれのまとまりの統一後の表記を選び直す

書き出し・保存

メソッド内容
toCSV({ bom })CSV 文字列。bom: true で Excel で文字化けしない。= などで始まる値は数式にならないよう ' を付ける
toJSON()data を返す（JSON.stringify(result) でも同じ）
toReport({ title })分析レポートの HTML 文字列（列の推論・変更・要確認の一覧）
toTableHTML() / toCardsHTML()表・カードの HTML 文字列（サーバー側で使える）
toPlain() / hydrate(plain)保存用の素のオブジェクトにする／そこから操作を付け直す

画面に表示する

result.render(要素, オプション) で、検索・並べ替えができる表やカードを描きます。result.renderReview(要素) は要確認を直す画面です。

render のオプション内容
view'table'（既定）か 'cards'
titleColumnカードの見出しにする列
virtual仮想スクロール。'auto'（既定：threshold 行を超えたら）・true・false
height / threshold仮想スクロールの表の高さ（既定 480px）／切り替える行数（既定 500）
batchカードを一度に描く枚数（既定 200。下までスクロールすると次を足す）
stylefalse で既定の CSS を入れない

戻り値のコントローラ：refresh()（値を直した後に描き直す）・setView('cards')・destroy()。

<tidy-table> タグ

JavaScript を書かずに、タグを置くだけで読み込み・正規化・表示ができます。

<script type="module" src="./nihon-tidy/src/view/element.js"></script>
<tidy-table src="customers.xlsx" view="cards" title-column="顧客名" report-button></tidy-table>
属性内容
src読み込むファイルの URL
view / title-columntable か cards ／ カードの見出しの列
sheet / min-confidenceExcel のシート ／ 提案にとどめる確信度
review / report-button要確認を直す画面 ／「分析レポートを開く」ボタン
plugins / workeraddress など ／ Web Worker で処理
height仮想スクロールの表の高さ（px）

イベント：tidy-load（読み込み完了）・tidy-change（修正のたび）・tidy-error。結果は e.detail または element.result。

Excel の複数段の見出し

「売上」の下に「上期・下期」があるような見出しを、売上・上期 のように 1 つの列名にします（最大 3 段）。データの行を見出しとして読み込まないよう、判定は控えめです。

  • 自動で判定するのは、見出し行から次の行へ縦に結合したセル（2 段にまたがる「店舗」など）があるときだけ
  • 縦の結合がなく 2 段かもしれない表は 1 段で読み、meta.headerNote に注意を残す
  • headerRows: 2 で段数を指定できる

住所プラグイン

plugins: ['address'] で住所の列を判定し、番地の書き方の統一や都道府県の補完を提案します。住所は自動では変えません（すべて提案。accept か acceptAll で適用）。

独自のプラグイン

列の種類の規則を足せます。規則は { type, label, hint?, match(value), normalize(value) } で、normalize は { value, confidence, note } か null を返します。

大きなファイル（Web Worker）

tidyInWorker は tidy と同じ結果を返し、処理の間も画面が止まりません。プラグインは名前（'address'）で指定します。Worker を使えない環境では tidy と同じに動きます。

段階ごとに呼ぶ

途中の結果を確かめたいときは、各段階を個別に呼べます。

コマンドライン

node bin/cli.js examples/sample-sjis.csv --report report.html --out output.json
node bin/cli.js examples/sample.xlsx --sheet 顧客一覧 --out output.csv   # CSV は BOM 付き
node bin/cli.js data.csv --plugins address --min-confidence 0.8
node bin/cli.js --help
